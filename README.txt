# Cherish website update package

This package incorporates the uploaded Excel plans into the website structure.

Included:
- index.html
- plan.html
- assets/js/common.js
- assets/js/menu.js
- assets/js/plan.js
- assets/css/main.css
- assets/css/plan.css
- menu.csv
- prices.csv
- plans.csv
- plan_meals.csv
- customization_options.csv

How to use:
1. Replace the matching files in your GitHub repo with these files.
2. Keep the CSV files at the repo root.
3. Commit and publish.

Plan URLs:
- plan.html?plan=elite
- plan.html?plan=salad
- plan.html?plan=weightloss
- plan.html?plan=basic
- plan.html?plan=customised
