How it works

Two separate journeys for instant orders and subscriptions.

À La Carte flow

  1. Browse live menu from catalog.
  2. Click Order on TMbill.
  3. Pay and complete order in TMbill.
  4. KOT is generated in TMbill.

Subscription flow

  1. Select Elite / Diabetic / Budget / Basic / Additional.
  2. Add optional add-ons and submit request.
  3. Team creates TMbill order and shares payment link / wallet top-up instruction.
  4. After payment in TMbill, KOT processing starts in TMbill.
